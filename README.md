# DSA-LC

A collection of my solved [LeetCode](https://leetcode.com/) problems, implemented in **C++**, organized by problem number and name. This repo tracks my ongoing practice with data structures and algorithms.

## Structure

Each problem has its own folder named `<problem-number>-<problem-title>`, containing a self-contained C++ solution file.

```
DSA-LC/
├── 33-search-in-rotated-sorted-array/
├── 150-evaluate-reverse-polish-notation/
├── 1023-time-based-key-value-store/
└── ...
```

## Topics covered

- **Binary Search** — e.g. Search in Rotated Sorted Array, Find Minimum in Rotated Sorted Array, First Bad Version, Peak Index in a Mountain Array
- **Stacks** — e.g. Evaluate Reverse Polish Notation, Build an Array with Stack Operations, Exclusive Time of Functions
- **Arrays & Two Pointers** — e.g. Longest Substring Without Repeating Characters, Successful Pairs of Spells and Potions
- **Intervals** — e.g. Remove Covered Intervals, Find Right Interval
- **Design / Data Structures** — e.g. Time Based Key-Value Store, Snapshot Array
- **Math** — e.g. Arranging Coins, Valid Perfect Square, Concatenate Non-Zero Digits and Multiply by Sum
- **Graphs** — e.g. Minimum Score of a Path Between Two Cities

## Building & running a solution

Each solution can be compiled independently. From within a problem's folder:

```bash
g++ -std=c++17 -O2 -o solution solution.cpp
./solution
```

(Adjust the filename above to match the `.cpp` file in that folder.)
